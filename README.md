# App Firewall (Android 6+)

فایروال ساده برای قطع اینترنت اپ‌های انتخابی بدون روت، با VpnService.

## نصب
1. پوشه را در Android Studio (نسخهٔ 4.1 یا 4.2) باز کنید.
2. Build > Make Project را بزنید.
3. گوشی را با USB Debugging وصل کنید و Run بزنید.
4. اپ را باز کنید، سوئیچ اپ‌ها را روشن کنید و اجازهٔ VPN را تأیید کنید.

## نکته
در حین فعال بودن فایروال نمی‌توانید VPN دیگری روشن کنید.
